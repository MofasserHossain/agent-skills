---
name: retro
description: "Improve the workflow environment after observing repeated friction or failures in real work."
---

Read the selected session/run artifacts and actual outcomes. Identify concrete causes of rework: missing context, unclear decisions, bad task boundaries, weak verification, expensive tools or unnecessary instructions.

Recommend the smallest supported correction. Mechanical recurring mistakes should become deterministic checks where practical. Judgment problems belong in focused guidance. Add navigation pointers rather than copying whole documentation into the base prompt.

Compare cost per accepted result, latency and review effort when data exists. Separate measured savings from hypotheses. Do not accumulate a universal rule for each isolated failure.

Apply authorized improvements and preserve the example that demonstrated the issue. Use [pilot scenarios](../../checks/pilot-scenarios.md) to evaluate behavioral changes.
