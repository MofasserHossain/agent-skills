# Precise reading pointers

An instruction should tell the agent when a document matters and what decision it supports.

Weak: “Read all guides before starting.”

More useful: “For changes to stored data, read the project's migration guide before choosing compatibility and rollback checks.” The project supplies the actual path; the shared skill does not invent one.

Weak: repeating the full testing policy in setup, implementation, review and every task.

More useful: one maintained project verification source, with focused commands or conditions referenced by the affected task. Keep its mandatory final checks discoverable; progressive disclosure must not hide required obligations.

For a resource used by only one skill, keep a local file and a local link. For a reusable discipline reached independently by several workflows, a named collaborator skill can be appropriate. If that collaborator is absent, report the missing guidance or continue only where the current procedure already suffices. A filesystem link outside the installed folder does not install the target.

Write completion in terms of evidence: “Every acceptance criterion has evidence or an explicit gap” is more checkable than “Be thorough.” Preserve exceptions that change behavior rather than making every example a universal rule.
